# 旗子保衛戰

一款以象棋棋子為主題的輕量塔防網頁遊戲。玩家需要部署旗子士兵、騎兵與主教，守住旗子並完成 30 回合。

## 開始遊玩

本遊戲不需要安裝套件或啟動伺服器：

1. 下載或複製專案。
2. 直接用瀏覽器開啟 `index.html`。
3. 點擊「開始遊戲」。

`index.html` 已內嵌 CSS 與 JavaScript，可完全離線遊玩。

## 遊戲規則

- 遊戲共有 30 回合。
- 第 1 回合從 10 格路線開始，之後每回合增加 1 格，最多 15 格。
- 路線方向在一局開始時生成，後續回合沿同一路線延長。
- 敵人沿路線前進，抵達旗子會造成傷害。
- 旗子初始生命為 3。
- 初始金幣為 2，每 1.5 秒增加 1 金幣。
- 每種旗子單位都有獨立冷卻時間。

## 敵人

| 敵人 | 生命值 | 移動規則 | 出現時間 |
| --- | ---: | --- | --- |
| 卒 | 1 | 每秒 1 格 | 第 1 回合起 |
| 兵 | 2 | 每秒 1 格 | 第 1 回合起 |
| 馬 | 2 | 每秒 2 格 | 第 4 回合起 |
| 瑪 | 3 | 每秒 2 格；可帶著卒與兵前進 | 第 4 回合起 |
| 包 | 4 | 每 2 秒 3 格 | 第 6 回合起 |
| 炮 | 5 | 每 1.5 秒 3 格 | 第 6 回合起 |

- 卒生成時會依回合數提高變成兵的機率：初始 20%，每 5 回合增加 2%，最高 100%。
- 馬出現時有 20% 機率變成瑪。
- 包出現時有 20% 機率變成炮。

## 旗子單位

| 單位 | 費用 | 能力 | 冷卻 |
| --- | ---: | --- | ---: |
| 旗子士兵 | 1 金幣 | 從終點出發，碰撞敵人後消失並造成 1 點傷害 | 1 秒 |
| 旗子騎兵 | 3 金幣 | 每秒追向最近敵人，碰撞後消失並造成 2 點傷害 | 2 秒 |
| 旗子主教 | 4 金幣 | 每秒提升自己與附近旗子單位的最大生命；每 2 秒遠程攻擊最近敵人並造成 1 點傷害 | 3 秒 |

旗子單位的最大生命值：

- 士兵：2
- 騎兵：3
- 主教：3

主教的最大生命提升效果不會超過各單位上限，同一秒內同一單位最多提升一次。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `1` | 派出旗子士兵 |
| `2` | 派出旗子騎兵 |
| `3` | 派出旗子主教 |
| `R` | 循環切換遊戲速度：1x → 2x → 3x |
| `Space` | 暫停／繼續遊戲 |

也可以使用畫面上的按鈕操作。

## 專案檔案

- `index.html`：可直接離線執行的單檔遊戲版本，內嵌 CSS 與 JavaScript。
- `style.css`：原始樣式檔，供開發與維護參考。
- `game.js`：原始遊戲邏輯檔，供開發與維護參考。

## 技術

- HTML5 Canvas
- 原生 JavaScript
- 原生 CSS
- 無框架、無外部套件、無網路依賴
